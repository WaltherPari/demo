## SwiftUI Example

`MontoInputView.swift` demonstrates how to create a numeric text field in SwiftUI.
It also includes a picker for selecting a categor\u00eda ("Educaci\u00f3n" or "Comida").
When tapping anywhere outside the controls, the numeric keyboard is dismissed.
